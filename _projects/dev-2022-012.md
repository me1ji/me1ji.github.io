## Overview
A console-based clinic logbook application designed to manage patient visits across three departments (SHS, JHS, Elementary) during a Work Immersion program. The system provides complete patient record management with data persistence per department.

### Challenge
Manual paper-based clinic logging was inefficient and error-prone for tracking patient visits across multiple departments.

### Solution
Built a structured Java application with department-separated data repositories and intuitive CLI interface for staff.

## Core Features
  - Patient registration with auto-timestamping
  - CRUD operations (Create, Read, Update, Delete)
  - Multi-department data separation
  - Formatted table display for patient records
  - Automatic data persistence (CSV storage)
  - Export data to Desktop
